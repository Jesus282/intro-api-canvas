# Proyecto Canvas Estilizado

## Descripción

Este proyecto consiste en la implementación de un elemento `<canvas>` utilizando HTML, CSS y JavaScript.  
Se desarrolla un rectángulo que ocupa el 50% del ancho y el 50% del alto de la pantalla, con un diseño moderno que incluye esquinas redondeadas, sombra y una combinación de colores en tonos café.

El objetivo principal es practicar el uso del API de Canvas en JavaScript junto con la personalización visual mediante CSS.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Canvas API)

---

## Características del proyecto

- Canvas centrado en pantalla.
- Dimensiones responsivas (50vw x 50vh).
- Esquinas redondeadas.
- Sombra externa para efecto visual moderno.
- Borde color café oscuro.
- Fondo color café claro.
- Código estructurado y comentado.

## Funcionamiento

1. El archivo HTML define el elemento `<canvas>`.
2. El archivo CSS aplica los estilos visuales:
   - Tamaño relativo a la ventana.
   - Sombra.
   - Bordes redondeados.
   - Colores.
3. El archivo JavaScript obtiene el contexto 2D del canvas y permite dibujar figuras en él.

---

## Objetivo de aprendizaje

- Comprender cómo funciona el contexto 2D del canvas.
- Manipular propiedades como `fillStyle`, `strokeStyle` y sombras.
- Aplicar estilos visuales modernos usando CSS.
- Integrar estructura HTML + CSS + JS en un proyecto simple.
